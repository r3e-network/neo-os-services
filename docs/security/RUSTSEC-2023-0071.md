# RUSTSEC-2023-0071 review

Status: reviewed exception, 2026-10-02

`cargo audit` reports `RUSTSEC-2023-0071` for `rsa 0.9.10` and states: "No fixed upgrade is available." The dependency is retained because the service
uses RustCrypto RSA for Nitro session transport and KMS Recipient unwraps.
The repository does not treat the advisory as silently cleared: the exact ID
is passed to `check-rust-audit.mjs`, the audit output must contain zero other
vulnerabilities, unsound or yanked warnings, and this document is covered by
the policy test. The advisory database must be fetched by the audit command
and its `last-updated` timestamp must be no more than 30 days old. The two
currently reviewed unmaintained warnings are `RUSTSEC-2024-0436` (`paste`) and
`RUSTSEC-2021-0127` (`serde_cbor`); any additional unmaintained warning fails
the gate.

The timing-risk boundary is reviewed as follows:

- `crates/nitro-attest/src/session_key.rs` uses `decrypt_blinded` for the
  session-token OAEP private operation.
- The same module uses `Pss::new_blinded_with_salt` for request-proof signing;
  its unit test rejects an RNG trace that draws only the PSS salt and verifies
  the resulting standard PSS signature.
- `crates/nitro-attest/src/cms.rs` uses `decrypt_blinded` for the KMS
  CiphertextForRecipient OAEP unwrap.
- `release.rs` and `nsm-attest-rs.rs` generate ephemeral keys and expose only
  public material until the CMS unwrap, which enters the blinded path above.
- The enclave host's other RSA use is public-key verification. No production
  private RSA operation may use the unblinded `decrypt` or an unblinded PSS
  signer.

This is a compensating control for an advisory without an upstream fixed
version, not a claim that the dependency is vulnerability-free. A future
`cargo audit` result for any advisory other than this exact ID fails the gate.
If an upstream fixed release or a replacement primitive becomes available,
the exception must be removed and the lockfile regenerated.

Validation command:

```text
npm run check:rust:audit
```

The command is a review and release gate; it does not modify `Cargo.lock`.
CI also runs `scripts/rust-security-audit-policy.test.mjs` directly so the
exception cannot be removed from the workflow while leaving the checker
uninvoked.
