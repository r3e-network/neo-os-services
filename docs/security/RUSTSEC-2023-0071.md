# RUSTSEC-2023-0071 review

Status: source remediation complete, 2026-10-03

NeoOS Services no longer includes RustCrypto `rsa` in its Cargo dependency
graph. All production RSA operations are routed through `aws-lc-rs` 1.18.1:

- Nitro Recipient and custody OAEP decryption use AWS-LC's private decrypting
  key API.
- Custody request proofs use AWS-LC RSA-PSS-SHA256 with the standard digest
  salt length.
- Compute and NeoDID RS256 verification use AWS-LC public-key verification.

The migration keeps the existing wire formats and rejects malformed key sizes,
ciphertexts, padding schemes, and signatures. The dependency gate asserts that
`Cargo.lock` contains no RustCrypto `rsa` package. The release audit is plain
`cargo audit`; it has no `--ignore RUSTSEC-2023-0071` exception and no vulnerability exception.

The source change is not a production deployment. Before a Nitro image can
release production ciphertext, the operator must rebuild and measure the image,
publish the resulting PCR manifest, and update the KMS key policy through the
existing deployment approval process. No such cloud or production operation was
performed by this change.

Validation is wired through:

```text
node --test scripts/rsa-provider-migration.test.mjs
node --test scripts/rust-security-dependency.test.mjs scripts/rust-security-audit-policy.test.mjs
npm run check:rust:audit
```
